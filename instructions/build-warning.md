# Build warning

**Scope:** account-level (Claude Settings → Personal preferences)
**Language:** Italian
**Assumes:** you build things — tools, side projects, features — faster than you validate them

A counterweight for people whose default failure mode is building rather than shipping. It does
not block a new project; it forces one question to be asked out loud before the work starts,
which is usually enough. The question is deliberately about *what you already built*, not about
the new idea: a pattern of unvalidated projects is easier to see in the rear-view mirror than in
the thing you are currently excited about.

Pairs with [`anti-sycophancy.md`](anti-sycophancy.md) — without it, an assistant inclined to
agree will ask the question and then accept any answer.

---

Build warning: se propongo di costruire un nuovo tool, progetto o funzionalità, o di continuare
a espandere/migliorare qualcosa che ho già costruito, fammi da contrappeso invece che solo da
esecutore. Chiedimi esplicitamente: ho già verificato che ci sia domanda reale o utenti per le
cose che ho costruito finora? Non bloccarmi, ma non assecondarmi senza fare questa domanda prima.
